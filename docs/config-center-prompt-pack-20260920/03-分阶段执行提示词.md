# 分阶段执行提示词：P00–P11

用法：先给执行模型01总控和04数据库事实，让它读取当前仓库；每次再给一个阶段及所列02规格章节。不要要求弱模型一次生成全部文件。下列提示词可以直接复制；文件相对路径均相对用户授权工作区。

阶段结束不是重复审批点：用户只授权单阶段时停在该阶段；用户已授权整个开发时按顺序继续，普通实现细节自行处理。需要真实认证、未确定的采集合约、生产写授权时，只暂停依赖项。不能用暂停理由掩盖其他可完成工作。

统一阶段交付格式：本阶段结果；修改文件；复用函数；实际测试/行为证据；未通过的验收ID与原因；下一阶段。没有运行的检查标记未运行，不写“理论上通过”。
