# 配置管理中心验收矩阵

本表是未来实现的验收要求，不代表本轮已执行。当前生成提示词阶段仅完成：Supabase只读结构/聚合核验、代码审计、3条关键纯函数/接口形状复现、现有47/47测试基线。未实施本表修复，未执行真实业务写入/删除/合并/采集。

执行时给每行填写：通过/失败/阻塞/不适用；证据位置；环境；时间；代码版本。`不适用`要说明原因，不能将缺runner或缺隔离数据库写成不适用。通过的单元测试不能替代标为真实回读的验收。

## 1. 分层与测试数据

- L1：纯函数/内存DB/模拟REST，故障可控，不碰生产。
- L2：本机HTTP与真实浏览器，使用隔离service或授权只读接口。
- L3：真实Supabase只读，验证结构/查询/计数/筛选。
- L4：隔离Supabase真实写回、删除、合并，或用户明确授权的目标写入。未具备环境则标阻塞。
- L5：真实外部执行入口、结果和回读，需要已授权的范围/配额/凭据。

测试样例必须明确是fixtures，不能显示在真实列表冒充业务数据。正向样例之外必须包含空值、边界、冲突、部分失败、超时结果未知。
